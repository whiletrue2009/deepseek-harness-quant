# 数据说明

## 数据边界（务必阅读）

**本仓库不包含任何真实行情数据。**

- 行情/财报数据来自第三方数据源（Tushare / akshare / baostock），其使用协议**禁止数据再分发、禁止转售、禁止账号共享**。
- 仓库仅提供：
  1. 数据获取脚本（`data/fetcher_*.py`、`bulk_loader.py`、`incremental_daily.py` 等，用户自行运行、自行持有数据）；
  2. 演示用**合成数据**（`data/demo/`，随机游走生成，仅用于界面/流程演示，与真实市场无关）。
- 请遵守各数据源条款；因数据使用产生的任何合规问题由使用者自行负责。

## 数据目录与配置

| 方式 | 优先级 | 说明 |
|---|---|---|
| 环境变量 `LWQUANT_CACHE_DIR` | 1（最高） | 指向数据目录（如 `D:\my_quant_data`） |
| `config/params.yaml` → `data.cache_dir` | 2 | 绝对/相对路径均可 |
| 默认 | 3 | 仓库内 `data/cache` |

核心库（在数据目录下）：

| 文件 | 内容 |
|---|---|
| `bars.db` | 日线（code/date/OHLCV/turn/amount，`adjust='qfq'` 前复权） |
| `bars_incr.db` | 日线增量库（与主库合并读取，增量优先） |
| `stock_basic.db` | 股票列表（含退市股标记） |
| `finance.db` | 财务摘要（无公告日，非 PIT） |
| `finance_quality.db` | 财务质量指标（无公告日，非 PIT） |
| `hist_mv.db` | 历史市值 |
| `lhb_full.db` | 龙虎榜 |
| `gdhs_full.db` | 股东户数 |

读取统一走 `data/cache.py`（唯一读取接口，自动合并主库+增量库）。

## 获取数据

当前仓库没有统一的 `data/fetch_data.py`。不要按旧命令执行 `--init/--daily`。

| 入口 | 数据源 | 说明 |
|---|---|---|
| `data/free_daily_pipeline.py` | Baostock + 同花顺 + 腾讯校验 | 默认免 Tushare 主管线：初始化、增量、质量、市值、择时与盘后刷新 |
| `data/free_daily_loader.py` | Baostock / 可选同花顺 | 日线初始化、增量、断点、失败清单与覆盖率 |
| `data/fetch_quality_ths.py` | 同花顺三表 | 财务质量指标；`pub_date=NULL`，非 PIT |
| `data/fetch_valuation_tencent.py` | 腾讯 | 当日 PE/PB/市值快照写入 `finance.db.valuation`；因子扫描只读本地表 |
| `data/fetcher_free.py` | 同花顺 + 腾讯 | 协议适配层：日线、财务、实时快照与单位标准化 |
| `data/fetcher_finance.py` | AKShare/同花顺 | 财务摘要，支持 `--limit/--start/--status` |

当前默认日线源是 Baostock，原因是它免 token 且完整提供 `amount/turn/is_st`。同花顺日线接口保留为可选备源；本机实测部分年度返回 502，不能当成已验活主源。

当前免费真实链的研究 Universe 是沪深 A 股。北交所清单可用 AKShare/腾讯获取，部分北交所代码可用腾讯或同花顺查询，但尚未纳入 `stock_basic.db`、全市场日线、ST 与退市审计，因此不能把当前结论称为“全 A”。

- Tushare 默认禁用：`data.tushare_token` 与 `data.tushare_api_url` 留空。
- akshare 免费无需 token，当前主要用于业绩预告/快报、机构调研等覆盖数据。
- 数据时间边界：换手率（turn）字段 2019 年起覆盖 90%+；**2019 年前换手率缺失，勿用 2019 前数据做换手类因子结论**

## 演示数据（合成）

`data/demo/build_demo_db.py` 生成 30 只合成股票 × 250 个交易日：

```bash
.venv/bin/python data/demo/build_demo_db.py
set LWQUANT_CACHE_DIR=data/demo
.venv/bin/python deck/deck_server.py
```

- 合成逻辑：随机游走 + 固定随机种子（可复现），schema 与真实 bars.db 一致
- **仅用于界面演示**；所有页面在演示模式下仍可浏览（数据为空/示例时页面会显示占位）
