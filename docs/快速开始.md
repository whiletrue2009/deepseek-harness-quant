# 快速开始

本文档覆盖：环境准备 → 配置 → 数据 → 启动 → 演示模式 → 一键 EXE。macOS 免 Tushare 运行优先阅读 [macOS 运行指南](macOS运行指南.md)。

## 1. 环境准备

- Python **3.10 ~ 3.12**（3.13+ 部分依赖如 vectorbt 可能无法安装；若只跑核心系统，3.13 亦可）
- Windows / Linux / macOS 均可（路径示例以 Windows 为准）

```bash
uv venv --python 3.12 .venv
uv pip install --python .venv/bin/python -r requirements.txt
```

macOS/Linux 统一执行 `.venv/bin/python`；Windows 对应 `.venv/Scripts/python.exe`。不要直接用主机 Python 运行本仓库。

> 完整依赖以 `requirements.txt` 为准。默认数据链不需要 Tushare；不要用主机 Python 直接安装或运行。

## 2. 配置

```bash
cp config/params.yaml.example config/params.yaml
```

打开 `config/params.yaml` 填写：

| 配置项 | 说明 |
|---|---|
| `data.cache_dir` | 数据目录（SQLite/Parquet 存放处）。留空则默认 `data/cache`；也可用环境变量 `LWQUANT_CACHE_DIR` 覆盖（优先级最高） |
| `data.tushare_token` | 保持空串；默认免 Tushare 链路不读取它 |
| 其余策略参数 | 均为阈值/权重，保持默认即可；改参数不改代码 |

## 3. 获取数据

默认入口是 `data/free_daily_pipeline.py`，不需要 Tushare token。

```bash
# 已有样本缓存，30 只体验
.venv/bin/python -X utf8 data/free_daily_pipeline.py --sample 30

# 空缓存全市场初始化（可中断续传，建议先跳过财务全量）
.venv/bin/python -X utf8 data/free_daily_pipeline.py --init --skip-quality --skip-refresh

# 日线与退市股完成后，补齐质量表和财务摘要
.venv/bin/python -X utf8 data/fetch_quality_ths.py --run --quarters 10 --rate 0.10 --workers 2
.venv/bin/python -X utf8 data/fetcher_finance.py

# 每个交易日收盘后增量刷新
.venv/bin/python -X utf8 data/free_daily_pipeline.py
```

全市场日线和财务质量都需要较长时间。分步补齐方式见 macOS 手册。

详细边界见 [数据说明](数据说明.md) 与 [macOS 运行指南](macOS运行指南.md)。

## 4. 启动

```bash
.venv/bin/python deck/deck_server.py  # 已激活虚拟环境时可用 python
scripts/run_macos.sh                   # macOS：.venv + 统一缓存目录 + HARNESS，默认 8787
```

浏览器打开 **http://127.0.0.1:8787**（门户）。

常用页面：

| 路径 | 页面 |
|---|---|
| `/` | 门户（KPI + 择时 + 实时信息） |
| `/pitch` | 决策（Pitch 候选卡 + 审批） |
| `/holdings` | 持仓 |
| `/factors` | 因子池 |
| `/backtest` | 回测归档 |
| `/etf` | ETF 映射（策略暴露 → ETF 相关性/配置） |
| `/pitchtrack` | 主观多池远期（五池对比 + 牛散决策者分组） |
| `/control` | 控制台（系统状态；「控制/HARNESS 对话」需另装 DeepSeek HARNESS，未装则显示未连接） |

## 5. 演示模式（无真实数据先看界面）

```bash
.venv/bin/python data/demo/build_demo_db.py
export LWQUANT_CACHE_DIR=data/demo
.venv/bin/python deck/deck_server.py
```

Windows 下对应 `.venv\Scripts\python.exe`，并把 `export` 换成 `set`。

> 演示数据明显为合成序列，仅用于验证 UI/流程，**不得用于任何策略结论**。

## 6. 一键 EXE（Windows）

仓库 `dist/QuantDeck.exe`（或自行打包，见下文）：

- 双击即启动服务（127.0.0.1:8787）并自动打开浏览器
- EXE 不含 akshare 数据拉取能力（体积/稳定性考虑）——数据获取请使用 Python 环境
- EXE 同目录需有 `data/`（数据目录）；也可设置系统环境变量 `LWQUANT_CACHE_DIR` 指向数据位置

### 自行打包 EXE

```bash
python -m pip install pyinstaller
python scripts/build_exe.py
# 产物: dist/QuantDeck.exe
```
